This screen — Tag management (/admin/tags)

  • The author edits and deletes tags and controls the home page's tag list (§4.4). There is no create form: a tag is created the first time a post uses it.
  • A Home order list of the home tags' names: drag a row by its handle, or use the up/down buttons, to change the order shown on the home page. It saves on drop. It appears when two or more tags are on the home page (§7.5 Home tag order list).
  • Below, every tag is its own form: a link to its public page with N posts, name (required), description (optional), a Show on the home page checkbox, and Save · Delete.
  • Delete opens a confirm dialog first; the tag then comes off every post that carried it, and no post is deleted (§5.3, §7.5 Confirm dialog).
  • When there are none: "No tags yet. A tag is created the first time a post uses it."
