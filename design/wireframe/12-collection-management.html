This screen — Collection management (/admin/collections)

  • The author creates, edits, and deletes collections (§4.4).
  • A create form at the top: title (required) · description (optional) · rules as a tag input (comma-separated, existing tags beneath as toggles) · "Add collection".
  • An Order list of the collection titles: drag a row by its handle, or use the up/down buttons, to change the order shown on the home page. It saves on drop (§4.4, §7.5 Collection order list).
  • Below, every collection is its own editable form with the same three fields prefilled, a link to its public page with N posts, and Save · Delete.
  • Rules: a post must carry every rule tag; leaving rules empty makes the collection show every post (§5.3).
  • When there are none: "No collections yet."
