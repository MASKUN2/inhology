This screen — Home / post list (/)

  • The entry screen: published posts, newest first.
  • Made of the site header (wordmark · Home · Admin menu) and, in the body, the home tag list and the tag bar. There is no title banner: the header's wordmark is the only site title. There is no post list here: posts are reached through a tag or through All (§4.2).
  • The home tag list shows the tags the author put on the home page, in the order set in the admin: name (opens the tag page), post count, and description. Its fixed last row, All, opens the list of every post (§4.3, §7.5 Home tag list).
  • The tag bar lists every tag that has published posts as a badge with its post count, highest count first; a badge opens that tag's page (§4.3, §7.5 Tag bar).
  • Drafts are never shown or counted. Private posts are counted like published ones; only their body is withheld from readers (§5.1).
