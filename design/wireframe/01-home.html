This screen — Home / post list (/)

  • The entry screen: published posts, newest first.
  • Made of the site header (wordmark · Home · Admin menu) and the body's site title/subtitle, the collection list, the tag bar, and the post card list.
  • The collection list shows every collection: title (opens the collection page), the number of posts it currently shows, and its description. It is hidden when there are none (§4.4, §7.5 Collection list).
  • The tag bar lists every tag that has published posts as a badge with its post count, highest count first; a badge opens that tag's page (§4.3, §7.5 Tag bar).
  • Each card carries a meta row (publish date · reading time N min), title, excerpt, and all of the post's tags as badges. There is no category and no series (§5.3).
  • Drafts are never shown (§5.1).
  • When there are none: "No posts published yet."
