This screen — Home / post list (/)

  • The entry screen: published posts, newest first.
  • Made of the site header (wordmark · Home · Admin menu) and the body's site title/subtitle, the collection list, and the tag bar. There is no post list here: posts are reached through a collection or a tag (§4.2).
  • The collection list shows every collection, in the order the author set in the admin: title (opens the collection page), the number of posts it currently shows, and its description. A rule-less collection such as All lists every post. It is hidden when there are none (§4.4, §7.5 Collection list).
  • The tag bar lists every tag that has published posts as a badge with its post count, highest count first; a badge opens that tag's page (§4.3, §7.5 Tag bar).
  • Drafts are never shown (§5.1).
